Por qué el open source cambió como vemos compartir lo que hacemos

Publicado el 14 de septiembre de 2026 · Por Nicolás Pieroni

1. Tres ideas sobre por qué se comparte el código

Nota 01

Copiar no es fabricar otra unidad

El software tiene una característica bastante particular: una vez que está hecho, duplicarlo cuesta muy poco. No hay que fabricar otra unidad física ni enviar un camión para que otra persona pueda usarlo. Esa diferencia en el costo marginal casi nulo cambia las reglas del mercado para nosotros. Ahora es más fácil hacer software.

Nota 02

Una base común evita repetir trabajo

Si el conocimiento queda encerrado, cada equipo vuelve a pagar por resolver problemas parecidos. Si el código se comparte, una mejora puede viajar de un proyecto a otro y convertirse en una base para muchas personas.

Nota 03

El trabajo puede volver mejorado

Una persona publica una solución, otras la prueban en contextos diferentes y la comunidad encuentra errores o propone mejoras. La herramienta vuelve a estar disponible para todos, con más contexto que al principio.

Compartir no elimina el valor: hace que el esfuerzo inicial pueda servirle a mucha más gente.

  • Una persona publica una solución.
  • Otras la prueban en contextos diferentes.
  • La comunidad encuentra errores y propone mejoras.

2. De la ciencia al trabajo compartido

La ciencia ya tenía una forma de avanzar parecida: publicar ideas, permitir que otros las revisen y construir sobre lo que ya existe. El open source lleva esa lógica a una parte industrial y cotidiana del trabajo tecnológico. Por eso me parece una de las pocas formas en las que muchas personas pueden trabajar juntas en una tarea común sin quitarles a los demás la posibilidad de usar lo producido.

El software open source puede ser accedido, usado, cambiado y compartido por cualquiera.

Open Source Initiative

3. Productividad que vuelve a la comunidad

Como desarrolladores, no solo entregamos funcionalidades: también podemos dejar herramientas, documentación y aprendizajes que otros aprovechen. El open source no funciona porque nadie cobre nunca, sino porque existe una comunidad capaz de compartir una base común y encontrar distintos modelos para sostenerla.

En ese sentido, el código se vuelve una forma de comunicación entre desarrolladores y puede generar un aumento productivo para todos, incluso cuando la primera contribución se hizo de forma desinteresada.

El software open source transformó nuestro mundo y se convirtió en la columna vertebral de nuestra economía digital.

Para seguir pensando

La pregunta no es solamente quién escribió el código, sino cuántas personas pueden aprender, mejorar y producir a partir de él.

Si generar código se vuelve cada vez más barato por la innovación de herramientas, el desafío para el open source cambia: ya no alcanza con compartir código; también hay que revisarlo, mantenerlo y decidir qué vale la pena conservar.

La IA puede acelerar la producción, pero también llenar repositorios con código repetido o difícil de verificar. La colaboración humana sigue siendo necesaria para cuidar la calidad, el contexto y la responsabilidad.
